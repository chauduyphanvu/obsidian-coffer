Coffer syncs your Obsidian vault through storage that you control. It encrypts all data on your device, merges changes from all your devices, and needs no server. It can also share folders with other people and publish notes as a website, like this one.

Coffer is free and open source (MIT). In Obsidian, find it under **Settings → Community plugins → Browse**. The code is on [GitHub](https://github.com/chauduyphanvu/obsidian-coffer).

> [!note] Coffer made this website
> These pages are Obsidian notes in the `docs` folder of Coffer's repository. Coffer's command line turned them into web pages, and GitHub Pages serves them. See [[Website]].
